CS50x — Introduction to Computer Science

This repository contains my solutions, labs, and projects completed during Harvard University's CS50x: Introduction to Computer Science course.

CS50x is an introduction to the intellectual enterprises of computer science and the art of programming. The course focuses on developing strong problem-solving skills while exploring fundamental concepts behind modern software development.

📚 Course Overview

Throughout this course, I explored how computers work, how software is designed, and how to solve complex problems efficiently.
